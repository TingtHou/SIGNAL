Axolotl brain (Stereo-seq)

This page analyses single-cell resolution Stereo-seq data of the axolotl brain at developmental stage 57 (Wei et al., 2022), with cell-type labels and the panel of 11 spatial kernels. To keep the page quick, it runs three genes named in the paper; the analysis of all 16,586 genes uses the same code and is best split into batches on a cluster (below).

Data

The processed data used on this page, artista_data.RData, can be downloaded from the SIGNAL real data folder on Google Drive. The raw data are in the ARTISTA database (https://db.cngb.org/stomics/artista/download/); we removed mitochondrial genes, kept genes with non-zero expression in at least 20 locations and locations with non-zero expression for at least 20 genes.

library(SIGNAL)
library(Matrix)
load("artista_data.RData")
dim(data_use$count_use)

Step 1: create a SIGNAL object

Three genes from the paper: AACS, a cell-type gene; TCF4, a spatial gene; and SDC2, a gene with a cell-type-specific spatial pattern.

genes <- c("AACS", "TCF4", "SDC2")
obj <- createSIGNALobject(data_use$count_use[genes, ], data_use$location_coord,
                          data_use$cluster)
obj
#> SIGNAL object: SIGNAL 
#>   3 genes x 4410 cells, 6 cell types
#>   Steps run: none

Step 2: filter and transform

obj <- SIGNAL_preprocess(obj, min_cells = 0, seed = 1)
#> Transforming 3 genes (rank)

Step 3: build the kernels

Cell-type labels give the Hamming cell-type kernel. With 4,410 cells (fewer than 6,000), SIGNAL builds the panel of 11 spatial kernels.

obj <- SIGNAL_kernel(obj)
#> Building spatial kernels for 4410 cells
names(obj@spatial_kernels)
#>  [1] "gaussian_1" "matern_1"   "gaussian_2" "matern_2"   "gaussian_3"
#>  [6] "matern_3"   "gaussian_4" "matern_4"   "gaussian_5" "matern_5"  
#> [11] "spline"

Step 4: test the genes

obj <- SIGNAL_test(obj, ncores = 3, verbose = FALSE)
signif(obj@result, 3)
#>      p_overall p_celltype p_spatial  p_ctSVG
#> AACS  1.11e-16   1.11e-16  6.48e-03 6.51e-01
#> TCF4  1.11e-16   7.69e-01  1.11e-16 3.74e-03
#> SDC2  1.11e-16   1.06e-01  3.33e-16 3.52e-06
res <- obj@result
apply(res[, c("p_celltype", "p_spatial", "p_ctSVG")] < 0.05, 1, function(f)
  paste(c("CellType", "Spatial", "ctSVG")[f], collapse = "+"))
#>               AACS               TCF4               SDC2 
#> "CellType+Spatial"    "Spatial+ctSVG"    "Spatial+ctSVG"

Values of about 1e-16 are below the accuracy of Davies’ method (about 1e-6); use method = "saddlepoint" to keep their actual size.

Step 5: visualise the genes

SIGNAL_plotGene(obj, "AACS", by_celltype = TRUE, point_size = 0.5)

SIGNAL_plotGene(obj, "TCF4", by_celltype = TRUE, point_size = 0.5)

SIGNAL_plotGene(obj, "SDC2", by_celltype = TRUE, point_size = 0.5)

Step 6: cell types behind the cell-type-specific pattern

obj <- SIGNAL_celltype(obj, genes = "SDC2", ncores = 3, verbose = FALSE)
signif(obj@celltype_result, 2)
#>         CP  EGC Immature_Neuron Mature_Neuron   NBL VLMC
#> SDC2 0.088 0.98         2.3e-06          0.91 0.094 0.99

All genes: batches on a cluster

The genes are tested independently, so the 16,586 genes can be split over the tasks of a Slurm job array, and the result tables combined afterwards:

part  <- as.integer(Sys.getenv("SLURM_ARRAY_TASK_ID"))
genes <- rownames(data_use$count_use)
batch <- genes[parallel::splitIndices(length(genes), 100)[[part]]]
obj <- SIGNAL(data_use$count_use[batch, ], data_use$location_coord, data_use$cluster,
              min_cells = 0, seed = 1)            # ncores = the Slurm allocation
saveRDS(obj@result, sprintf("artista_part_%03d.rds", part))
sbatch --array=1-100 --cpus-per-task=20 --mem-per-cpu=4G --time=24:00:00 run_artista.sh

With 4,410 cells, each spatial kernel takes about 17 minutes for 160 genes on 20 cores, so a batch of 160 genes needs about 3 hours and 30 GB of memory.
