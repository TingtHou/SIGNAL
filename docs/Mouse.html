Mouse hypothalamus (MERFISH)

This page analyses single-cell MERFISH data of the preoptic area of the mouse hypothalamus (Moffitt et al., 2018) with cell-type labels and a single Gaussian spatial kernel. To keep the page quick, it runs three genes named in the paper; the analysis of all 155 genes uses the same code.

Data

The processed data used on this page, Mouse_hypothalamic_preoptic.Rdata, can be downloaded from the SIGNAL real data folder on Google Drive. The data come from the BASS analysis page (https://zhengli09.github.io/BASS-Analysis/MERFISH.html): the tissue section at Bregma −0.09 mm from animal 1, with 155 genes on 5,557 cells.

library(SIGNAL)
library(Matrix)
load("Mouse_hypothalamic_preoptic.Rdata")
dim(data_use$count_use)
#> [1]  155 5557
table(data_use$cluster)
#> 
#>   Astrocyte Endothelial   Ependymal  Excitatory  Inhibitory   Microglia 
#>         634         428         305        1087        2530         108 
#> OD Immature   OD Mature   Pericytes 
#>         188         240          37

The 37 pericytes are too few for per-cell-type testing and are removed, leaving 5,520 cells in eight cell types:

keep     <- data_use$cluster != "Pericytes"
counts   <- data_use$count_use[, keep]
location <- data_use$location_coord[keep, ]
celltype <- droplevels(factor(data_use$cluster[keep]))

Step 1: create a SIGNAL object

Three genes from the paper: Gad1, a marker of inhibitory neurons; Cck, expressed in one region of the tissue across several cell types; and Gda, with different spatial patterns in inhibitory and excitatory neurons.

genes <- c("Gad1", "Cck", "Gda")
obj <- createSIGNALobject(counts[genes, ], location, celltype)
obj
#> SIGNAL object: SIGNAL 
#>   3 genes x 5520 cells, 8 cell types
#>   Steps run: none

Step 2: filter and transform

obj <- SIGNAL_preprocess(obj, min_cells = 0, seed = 1)
#> Transforming 3 genes (rank)

Step 3: build the kernels

The cell-type input is a vector of labels, so SIGNAL uses the Hamming cell-type kernel. As in CELINA’s approximation mode, we use one Gaussian spatial kernel (approximation = TRUE). Its bandwidth is chosen from the expression of all genes with Silverman’s rule; with only three genes in the object, we compute it from the full count matrix and pass it on:

bw <- select_bandwidth(counts)
bw
#> [1] 0.1060964
obj <- SIGNAL_kernel(obj, approximation = TRUE, bandwidth = bw)
#> Building one Gaussian spatial kernel for 5520 cells
#> Bandwidth: 0.1061
names(obj@spatial_kernels)
#> [1] "gaussian"

Step 4: test the genes

obj <- SIGNAL_test(obj, ncores = 3, verbose = FALSE)
signif(obj@result, 3)
#>      p_overall p_celltype p_spatial  p_ctSVG
#> Gad1  1.11e-16   1.11e-16  1.24e-03 4.75e-01
#> Cck   1.11e-16   1.11e-16  1.11e-16 3.76e-02
#> Gda   1.11e-16   1.11e-16  1.11e-16 2.91e-05

All three genes are detected by the overall test. Values of about 1e-16 are below the accuracy of Davies’ method (about 1e-6); use method = "saddlepoint" to keep their actual size.

res <- obj@result
apply(res[, c("p_celltype", "p_spatial", "p_ctSVG")] < 0.05, 1, function(f)
  paste(c("CellType", "Spatial", "ctSVG")[f], collapse = "+"))
#>                     Gad1                      Cck                      Gda 
#>       "CellType+Spatial" "CellType+Spatial+ctSVG" "CellType+Spatial+ctSVG"

Step 5: visualise the genes

SIGNAL_plotGene(obj, "Gad1", by_celltype = TRUE, point_size = 0.4)

SIGNAL_plotGene(obj, "Cck", by_celltype = TRUE, point_size = 0.4)

SIGNAL_plotGene(obj, "Gda", by_celltype = TRUE, point_size = 0.4)

Step 6: cell types behind the cell-type-specific pattern

obj <- SIGNAL_celltype(obj, genes = "Gda", ncores = 3, verbose = FALSE)
signif(obj@celltype_result, 2)
#>     Astrocyte Endothelial Ependymal Excitatory Inhibitory Microglia OD Immature

#>     OD Mature
#> Gda       0.3
